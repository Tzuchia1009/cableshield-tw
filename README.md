更新：2026年9月26日。正式分析單位為逐船、逐纜的接近片段；森林、自編碼器、前處理、百分位參照與每日 Top-K 均已依片段重建。

## 資料與事件定義

2023–2025年 NODASS AIS 共3,295,161筆觀測，搭配公開概化海纜路由。5公里內進入、觀測到超過6公里才記錄離開，5–6公里保留前狀態。超過6小時缺口或定位異常中斷證據鏈，缺訊不當作離開；跨日不自動拆段。

- 699,868個接近片段；675,020筆船舶－海纜－日彙總。
- 41,182筆每日彙總包含多段，不能一律視為已觀測到返回。
- 18,441個片段為24小時內有離開證據的返回；其中16,563個未通過模型門檻，仍保留查核線索。
- 39,280個合格片段（5.61%）已給模型分數。未合格片段保留空分數、品質原因、返回與缺口資訊。

## 模型及評估

| 用途 | 年度 | 合格片段 |
|---|---|---:|
| 訓練及參照 | 2023 | 15,398 |
| 驗證 | 2024 | 13,993 |
| 跨年度回溯測試 | 2025 | 9,889 |

前處理及模型只以2023年擬合。內部依11月1日切分選輪，跨分界12段暫不納入，前處理僅使用內部訓練段；三組種子均選到80輪上限後以全2023年重建。2025年資料已於資料重建時檢視，不稱首次開封的封存測試。

加權規則、300棵樹的 Isolation Forest、18→32→16→6→16→32→18自編碼器平行比較。三種分數以2023年經驗分布轉成百分位再等權組合。原日彙總模型、分數與舊百分位未載入本次實驗。

每日依片段最後觀測日（Asia/Taipei）歸檔；同船同纜不同片段不去重。同分依片段識別碼排序；個別方法使用原始分數避免百分位頂端飽和造成額外同分，組合使用平均百分位。K=1、3、5、10，2025年有356日具合格片段；Top-5每方法共1,724個片段名額。不足K時保留全部；未驗證即時結束判定或告警延遲。

2025年森林／自編碼器 Spearman=0.720，每日Top-5 Jaccard=0.438（按日重抽樣95%區間0.410–0.467）。區間未校正跨日自相關。2024年4,000個片段的特徵擾動測試，森林／自編碼器 AUROC=0.989／0.977，船舶群組重抽樣區間分別為0.986–0.992／0.973–0.980。擾動與規則特徵相近，規則AUROC接近1受測試設計影響，不能當成事故辨識能力。

南側2023年901段訓練、北側2024年11,942段且排除已見船舶的補充檢查，採觀測航程包絡及20公里緩衝；4,000段特徵擾動中，森林／自編碼器AUROC為0.755／0.804。區域及訓練量同時改變，結果限制了跨區推論。

## 展示、人工監督與來源

公開地圖只含匿名、概化歷史觀測：時間粗化6小時、位置0.05度，超過3小時缺口不連線。它不提供個體模型分數，也不能用來重建返回次數。模型頁只發布受控原始觀測分析後的彙總結果；船舶身分、個體分數、座標及模型權重未公開。

CableTrack既有GRU預測比較為獨立延伸，未參與CableRank片段排序。未做正式勤務、使用者或機關介接驗證，亦未以人工回饋回訓。模型分數僅供查核排序，事故認定、責任及處置由人員依正式程序決定。
