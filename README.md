# CableShield-TW 公開展示版

本頁展示 CableShield-TW「既有監控之後的證據化查核層」。目前以公開海纜代理、公開 WMS 地形及匿名／概化後的歷史 AIS 樣本，說明候選分流、證據缺口與人工查核介面；頁面採唯讀方式運作，未連接正式告警、通報或處置系統。

- 船名、MMSI、呼號、目的地、來源檔名與列號未發布。
- 位置約化至 0.05°，時間粗化為 6 小時，不適用航行、定位、執法或船舶意圖判定。
- 演練 A–F 的船位、航速、分數與因素全為合成情境。
- 海纜名稱與登陸點源自 TeleGeography via Gigawatt Map（CC BY-NC-SA 3.0）；路線為公開概化示意。
- 內政部 200 米海底地形及 ENC 圖框、GEBCO 為公開 WMS 圖層；本版不包含管制 ENC WMS。
- 本次競賽範圍不包含完整 ENC、即時 AIS、即時定位或即時告警；這些項目只列為未來建議擴充。

## 三層資料口徑

- G0 描述研究工作量：5 公里情境共有 674,710 筆船舶－海纜－日候選，1,094 個有效日期的每日中位數為 656.5。
- G1 描述模型可判性：651,729 筆最近海纜事件中，23,690 筆可進模型表，628,039 筆需補證。
- Top-K 描述人工深查預算：K 依查核人數、可用工時與單案時間調整；K=5 只作競賽示例。

三層回答的問題與分母不同，因此 657、3.6% 與 K 不能直接換算。

## 模型研究證據

2026-09-10 已在受控本機環境以 329.5 萬筆 NODASS 歷史 AIS 完成訓練：

- G1：Isolation Forest、深度自編碼器與固定規則的異常排序對照。
- G2：Ridge 與兩層 GRU 的下一筆真實 AIS 船位預測，另與位移延續及 AIS 速度航向物理外推比較。
- 切分固定為 2023 訓練、2024 驗證、2025 封存測試。
- GRU 沒有改善典型事件的中位誤差，但在 2025 概化海纜 20 km 子群將 p90／p95 誤差相對物理外推降低約 6.0%／15.8%。
- 公開頁的「模型研究」只提供彙總指標與限制；不發布受控 AIS、船舶身分、事件座標、逐事件排名或模型權重。

模型預測目標為下一筆 AIS 船位與歷史分布中的少見行為，不能解讀為惡意意圖、海纜事故準確率或實際海纜安全距離。地圖中的匿名歷史樣本與合成情境仍未附加個體模型結論。

## 人機協作與持續學習

資料點不足、缺訊過長、船舶身分衝突、來源過期、分布外樣本或海纜幾何不確定時，事件會退出自動 Top-K 並進入隔離佇列。人工查核以結構化欄位保存判斷、信心、理由、證據 ID、證據權威與標籤可用時間；公開頁可以演練與下載回饋候選，但不會直接改變模型。

一般標籤須達信心門檻；事故關聯標籤須至少兩位獨立審查者形成共識，並附一項官方結果。新聞只能作為事件脈絡，不能單獨成為訓練標籤。通過門檻的回饋只進入 Challenger 候選資料集，仍須依時間切分重訓、封存測試、校準與覆蓋率檢查，再由人員核准升格。

公開事故回溯包括 SHUNXIN 39／TPE、HONG TAI 58／TP3，以及 MIN LIAN YU 60138／TDM2。現有本地 AIS 在三案中均不足以重建事故航跡，因此系統正確處置是棄權與補證，不能宣稱事故命中。第三案的官方結論為過失毀損，也說明「發生損害」與「具有惡意」須分開認定。案例與治理規則可由「模型研究」頁下載。

數發部報告表 4–6 的 32 起 2025 年事件已轉為公開驗證框架：先區分 24 海浬內船舶威脅與遠海自然災害，再依公開身分、事故前 AIS 與海纜幾何逐關檢查可比性。報告事件只建立外部母體與標籤本體，不直接餵給模型作為事故正例。

完整研究版保留於資料所有人的本機環境。未來若由具資格單位取得管制圖資，應由受控後端代理並依核准的系統網址、外部 IP 與資料管制條件使用，不得提交到公開儲存庫。

建議導入順序為離線研究原型、取得授權後的只讀影子模式，以及通過成效與治理檢查後的有限介接。實際省時、Recall@K、人工覆寫率、角色權限及正式串接仍待未來場域驗證。
